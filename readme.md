# 进货簿

**一个人的小店记进货账。** 一个 PHP 文件、一个 SQLite 数据库，没有框架、没有 MySQL、不用构建，丢进任意支持 PHP 的目录就能用。

---

## 它做什么

记录「向批发商进货」的流水：一张进货单 = 一家批发商 + 一个日期 + 若干商品明细（名称 / 规格 / 单位 / 数量 / 单价）。

- **记账**：录入或补录进货单，金额随数量、单价实时合计
- **查账**：按关键词、批发商、日期翻历史单据，四张统计卡看单数、累计金额、本月金额
- **看报价**：查每家供货过哪些商品、最近报价多少、历史价格区间在哪
- **对账**：小计可以直接填实付总价，系统反算单价，除不尽的几分钱不再出现
- **留待复核**：数据存疑时先打个标记，事后按标记集中筛出来核对

数据库跟着目录走，首次访问自动建库，不需要任何配置。

## 特性

- **单文件**：程序只有一个 `index.php`，没有依赖、没有构建步骤
- **自带数据库**：SQLite 随目录存放，不需要装 MySQL，也不需要单独启服务
- **金额双向换算**：单价最少两位、最多四位，小计填总价可反算单价
- **输入辅助**：商品名联想、规格候选、历史报价浮层，都按「这家批发商」的历史来
- **严格日期校验**：校验真实日期（含闰年、月末），前端与后端各拦一次
- **待复核标记**：数据存疑时点一下「标记存疑」，事后勾筛选「只看待复核」集中核对
- **A4 单页打印**：抬头、合计、备注不拆分，表格行不跨页
- **移动端可用**：390px 宽度下操作列仍完整可见
- **零账号体系**：适合个人小店或内网单点，不适合直接公网暴露

## 快速开始

### 环境要求

| 项目 | 要求 |
| --- | --- |
| PHP | 8.0 及以上，启用 `pdo_sqlite`（PHP 默认自带） |
| 数据库 | 无需安装，程序首次访问自动生成 `orders.sqlite` |
| 浏览器 | 任意现代浏览器 |
| 其他 | 不需要 MySQL、Node、npm 或任何构建工具 |

### 启动

**本机最快**

```bash
php -S 127.0.0.1:8000 -t .
```

打开 <http://127.0.0.1:8000/>。`php -S` 是单进程，一次只处理一个请求，一个人用足够。

**已有站点**

把文件放进站点目录（Apache / Nginx / 宝塔 / phpstudy 都行），命名为 `index.php`，访问站点根路径即可。

**内网多人**

挂到 Apache / Nginx + php-fpm 后面，不要用 `php -S` 顶多人并发。

### 首次访问会发生什么

1. 在程序同目录创建 `orders.sqlite`，已存在则复用，不清空
2. 自动建表 `batches` / `items` / `wholesalers` 及索引；老库缺 `items.spec`、`batches.flag` / `flag_note` 列会自动补上
3. 批发商档案为空时，把历史进货单里出现过的批发商名导入一次；之后只在新增单据时增量补充

数据库按目录定位、不认文件名，移动目录时把 `orders.sqlite` 一起挪走。

## 使用说明

### 录入进货单

| 字段 | 说明 |
| --- | --- |
| 日期 | 点输入框弹日历（Tab 进来也会弹），也支持手输 `2026/1/5`、`2026.1.5`、`2026-1-5`，失焦补零 |
| 批发商 | 手输新名字，或从已有档案的下拉候选里选；非空即自动入档 |
| 商品名 | 输入 2 个字后按「这家批发商」的历史商品做模糊匹配（空格分词，多个词都要命中） |
| 规格 | 选填，`500ml 瓶装`、`10包×3层` 都行；填完商品名后按历史给候选 |
| 数量 | 最多两位小数，加减步长跟随小数位：整数 1、一位 0.1、两位 0.01 |
| 单价 | 最少两位、最多四位；点开浮出这家对这个商品的历史报价，点一条即填入 |
| 小计 | 平时自动显示「数量 × 单价」，也可以直接填本行实付总价，失焦后反算单价 |
| 存疑标记 | 「标记存疑」按钮，点一下点亮并转为「取消标记」，再点即取消；数据存疑即标记，原因写进备注，列表显示黄色徽章 |

明细行可增可删，底部实时显示总数量与合计金额；保存时日期必填并再次校验。

**日期必须真实存在**，不只校验格式。三个拦截点：录入失焦、保存提交、服务端写入。

| 输入 | 结果 |
| --- | --- |
| `2026-02-31` | 拒绝：该月没有这一天 |
| `2026-02-29` | 拒绝：2026 不是闰年 |
| `2024-02-29` | 通过 |
| `2026-13-01`、`2026-11-32` | 拒绝 |
| `2026/1/5`、`2026.1.5`、`2026-1-5` | 通过，归一化为 `2026-01-05` |

**金额精度口径**

整数价显示两位（`45.60`）；除不尽的价保留四位，例如 12.5 元 6 瓶的单价是 `2.0833`，小计按「数量 × 单价」四舍五入到分，`2.0833 × 6 = 12.50`。想按实付金额记账时，直接把总价填进「小计」，单价会自动反算；之后改数量或单价，小计回到自动计算。

### 进货记录

- 顶部四张统计卡：进货单数、累计金额、本月金额、本月单数，增删改后即时刷新
- 打了「待复核」的单，单号头上挂一枚黄色徽章，纯作提示，点它没有动作；具体原因看备注
- 搜索（商品名、规格、单位、批发商、备注）与筛选（批发商、日期）同时生效，已生效条件以 chip 展示，点 `×` 单独摘掉
- 点单据头上的日期或批发商名，可一键加入筛选
- 列表按「进货日期倒序 → 同日录入倒序」排列，补录旧单也会落到正确位置
- 每张单可展开看明细，右上角打印 / 编辑 / 删除；明细表点表头排序，点 `#` 恢复原始序号
- 分页：`共 N 条 · 每页 10 / 20 / 50 / 100`
- 打印为 A4 单页，打印期间重复点击会提示等待，取消不会把页面停在空白页

### 批发商管理

- **档案**：名称（必填）/ 联系人 / 电话 / 备注，列表里的「编辑」会把内容带上来
- **列表**：`#` / 批发商 / 联系人 / 联系电话 / 操作，标题右侧小灰字 `共 N 家`，搜索时变 `匹配 N 家`
- 多个号码按 `, ， 、 ; ； /` 拆开，一个号码一行；没填的显示浅灰 `—`
- **详情**：信息条竖排三行（联系人 / 电话 / 备注），底部统计进货单数、商品种类、累计数量、累计金额；商品表可按名称、单位、次数、数量、最新单价、报价日期、价格区间排序，并支持按商品名搜索

### 待复核标记

单据看不清、数据存疑、疑似同音字或漏字、补录很久以前的单，都不必当场核对完再存：

- 录入或编辑时点一下「标记存疑」按钮即点亮（按钮内方框打勾，文字转为「取消标记」），再点一下即取消；原因照旧写进「备注」，不再单设说明框
- 状态一眼可辨：方框为空 + 灰字「标记存疑」= 未标记；方框打勾 + 琥珀色 + 「取消标记」= 已标记
- 点按钮**只切换状态、不保存**：状态随「保存进货单 / 保存修改」一起落库
- 备注里写清疑问点即可，例如「8 号那行数量没认准」「名称疑似同音字」「单价像是抄错一行」
- 这类单在列表里挂黄色徽章，仅作提示；要看全部待核对的单，勾筛选区「只看待复核」（勾选项本身就是状态，不再另出条件 chip）
- 配合搜索框可再窄一层：关键词会把备注一起搜，记得「补录」两个字也能捞出来
- **取消标记只能在编辑里改**：点开「编辑」，再点一下已点亮的按钮，即随保存一起取消
- 按钮处于点亮状态时，编辑页打开即自动点亮

### 几条约定的规则

- **规格可以为空**，空的就不显示、不占位；详情里取该商品最近一次填过的规格
- **最新报价**不是「最后插入的那条」，而是按 `进货日期 → 进货单 id → 明细 id` 逐级比较，补录旧单不会把老价格顶成最新价
- **改名与删除**：批发商改名会同步历史单据里的名字；删除批发商只删档案，名下单据原样保留
- **服务端兜底**：绕过页面直接发请求，非法日期和超范围数值同样写不进去

## 数据与备份

- **备份就是一个文件**：复制 `orders.sqlite`；若目录里有 `-wal` / `-shm`，停服务后三个一起拷最稳
- **换机器**：程序文件 + `orders.sqlite` 拷走即用
- **导出数据**：用 DB Browser for SQLite 打开 `orders.sqlite`，把 `items` 导出 CSV
- **改主题色**：CSS 顶部 `:root` 里的 `--primary` / `--primary-strong`
- **改打印版式**：只改 CSS 中 `#printArea` 那一批规则，页面内打印与打印窗口共用

金额不存冗余汇总字段，永远实时 `SUM(qty * price)`，避免账实不符。

## 部署与安全

程序本身没有账号与权限体系，**不要直接暴露在公网**。至少做一层访问限制：

- 站点层 Basic Auth
- 只监听内网地址，或绑定 `127.0.0.1`
- 前置 VPN / 反向代理鉴权
- 关闭目录列表，并定期备份 `orders.sqlite`

## 常见问题

**`php -l` 报 `Module "com_dotnet" is already loaded`？**
看到 `No syntax errors detected` 就行，那条是 PHP 配置重复加载扩展的告警，与本系统无关。

**`php -S` 下页面偶尔卡一下？**
内置服务器单进程，一次只处理一个请求。自用够用，多人请上 php-fpm。

**改了程序文件名，数据还在吗？**
在。数据库按目录定位，不认文件名。

**删掉的批发商会不会又冒出来？**
不会。自动导入只在档案为空时执行一次，之后只在新增进货单时增量补充。

**日期一定要手打成 `2026-01-05` 吗？**
不用。`2026/1/5`、`2026.1.5`、`2026-1-5` 失焦后都会补零成标准格式，点输入框还能直接弹日历。

**某家「进货单数」和列表单据数对不上？**
两者都按批发商名称统计，名字首尾空白（含全角空格、不换行空格）在保存入库、档案保存、启动清洗三处统一处理。手工改过数据库里的 `batches.wholesaler` 而没同步改名，口径仍会断；在页面上改名不会有这个问题。

## 数据结构与接口

<details>
<summary>点击展开：数据库表结构</summary>

`orders.sqlite` 与程序文件同目录。

```sql
batches        -- 进货单，一单一条
  id          INTEGER PK
  wholesaler  TEXT    -- 批发商名（对应 wholesalers.name）
  odate       TEXT    -- 进货日期 YYYY-MM-DD
  note        TEXT
  flag        INTEGER -- 1 = 待复核，0 = 正常
  flag_note   TEXT    -- 旧版标记说明，已退役，新数据写空
  created_at  TEXT

items          -- 单据里的商品明细
  id          INTEGER PK
  batch_id    INTEGER -- → batches.id
  name        TEXT
  spec        TEXT    -- 规格，可空
  unit        TEXT
  qty         REAL
  price       REAL    -- 单价，最多四位小数

wholesalers    -- 批发商档案
  id          INTEGER PK
  name        TEXT    -- 唯一索引
  contact     TEXT
  phone       TEXT
  note        TEXT
  created_at  TEXT
```

</details>

<summary>点击展开：HTTP 接口</summary>

所有交互走同一入口，用 `?ajax=` 区分，返回 JSON（中文不转义）。

| 端点 | 方法 | 参数 | 作用 |
| --- | --- | --- | --- |
| `?ajax=list` | GET | `q`、`d`、`w`、`f`、`page`、`per` | 列表 HTML + 分页；`f=1` 只看待复核 |
| `?ajax=stats` | GET | — | 统计数（含 `flagged_count` 待复核单数） |
| `?ajax=batch&id=` | GET | `id` | 单张单 + 明细（编辑用） |
| `?ajax=save` | POST | `id`（0 = 新增）、`odate`、`wholesaler`、`note`、`flag`、`items[]` | 新增 / 更新（事务写入，服务端校验日期；复核状态随本接口一起提交） |
| `?ajax=delete` | POST | `id` | 删除整单（含明细） |
| `?ajax=unflag` | POST | `id` | 取消待复核标记（接口保留，页面已无入口，取消改在编辑里做） |
| `?ajax=whlist` | GET | — | 批发商列表 + 各自单数 / 金额 |
| `?ajax=whdetail&id=` | GET | `id` | 该家供货商品、最新单价、历史区间 |
| `?ajax=wsave` | POST | `id`、`name`、`contact`、`phone`、`note` | 新增 / 修改批发商（改名同步历史单） |
| `?ajax=wdelete` | POST | `id` | 删除批发商档案（不动进货单） |
| `?ajax=prices&w=` | GET | `w` | 该家每个商品最近 8 个历史单价 |
| `?ajax=specs&w=&n=` | GET | `w`、`n` | 该商品最近 12 条历史规格 |
| `?ajax=names&q=&w=&scope=` | GET | `q`、`w`、`scope=wh/all` | 商品名联想；`q` 空时返回该家商品总数，少于 15 种连清单一起给 |
