# 进货簿

> 单文件进货记账系统：一个 PHP 文件 + 一个 SQLite 数据库

给一个人的小店记账用。没有框架、没有 MySQL、没有构建步骤、不需要联网，丢进任何有 PHP 的机器就能跑；换电脑就是把两个文件拷过去。

---

## 一、三问定位

| 问题 | 回答 |
| --- | --- |
| **这是什么？** | 记录「向批发商进货」的账本。<br />一张进货单 = 一个批发商 + 一个日期 + 若干商品明细（名称 / 单位 / 数量 / 单价）。 |
| **有什么用？** | 替代纸本账。能按日期、按批发商、按关键词翻历史；<br />自动算出每家进了多少单、花了多少钱；<br />还能查某家供货过哪些商品、最近报价多少、历史价格区间在哪。 |
| **怎么用？** | 打开页面 → 「录入进货单」记账 → 「进货记录」查账 → 「批发商管理」<br />维护联系人、看每家报价。首次访问自动建库，不用配置。 |

## 二、跑起来

### 环境

- **PHP 8.0+**（用了 `strict_types`、标量类型声明、`Throwable`）
- 扩展：`pdo_sqlite`（PHP 自带）
- 浏览器：Chrome / Edge / Firefox 任一现代版本
- 不需要：MySQL、Nginx 规则、Node、任何构建工具

### 启动

**A. 本机最省事**

```bash
php -S 127.0.0.1:8000 -t "D:\app\进货簿"
```

然后访问 `http://127.0.0.1:8000/`。

**B. 挂到已有站点（宝塔 / phpstudy / Apache）**

把程序文件放进站点目录、命名成 `index.php`，访问站点根路径即可。文件名不固定，叫什么都能跑，只是 `index.php` 地址最短。

**C. 内网多人用**

挂到 Apache / Nginx / php-fpm 后面。`php -S` 是单进程，多人同时操作会排队。

> **没有登录和权限控制**，设计前提是「自己用 / 内网用」。
> 要放公网请自己加一层访问限制（Basic Auth、内网绑定、VPN），别裸奔。

### 首次访问会发生什么

1. 在程序文件**同目录**创建 `orders.sqlite`（已存在则复用，不清空）；
2. 自动建表 `batches` / `items` / `wholesalers` 及索引；
3. 若批发商表为空，把历史进货单里出现过的批发商名导入一次（之后不再自动导入，删掉的不复活）。

> 数据库跟着**目录**走，不认文件名。移动目录时把 `orders.sqlite` 一起挪。

## 三、三个功能页

### 1. 进货记录

**顶部四张统计卡**：进货单数 / 累计金额 / 本月金额 / 本月单数，任何增删改后即时刷新。

**搜索与筛选分两块，逻辑上是「同时满足」：**

| 区域 | 作用 |
| --- | --- |
| 搜索区 | 关键词 + 搜索按钮。匹配商品名、单位、批发商、备注，命中文字高亮 |
| 筛选区 | 批发商下拉 + 日期 + 清除筛选；已生效条件显示成 chip，点 × 单独摘掉 |
| 组合 | 关键词 ∧ 批发商 ∧ 日期，三者任意叠加 |

**日期筛选框点一下输入框就弹日历**（也可以点右边小图标，或直接手打 `2026-1-5`），不用先点图标。

**快捷操作**：点单头上的**日期** → 该日期自动进筛选；点**批发商名** → 只看这一家。

**列表**：按「进货日期倒序 → 同日按录入顺序倒序」排列，补录旧单也会落在正确位置。每张单可展开看明细，右上角有 打印 / 编辑 / 删除。

**分页**：`共 N 条 · 每页 [10 / 20 / 50 / 100] 条`，下拉在分页条右侧，切换后回到第 1 页。

**打印**：A4 排版（15mm 页边距），只输出单据本体，页面 UI 全部隐藏。

### 2. 录入 / 编辑进货单

- 日期：**点输入框即弹日历**（键盘 Tab 进来也会弹），也支持手输 `2026-1-5` 自动补零。已聚焦时再点不重复弹，方便接着手打。
- 批发商：可手输新名字，也可用已有批发商的下拉候选。
- **单价**：纯手动输入，**隐藏上下箭头、不响应滚轮**（避免滚动列表时误改价格），失焦自动补成两位小数（`12` → `12.00`）。
- **单价联动历史价**：填完批发商和商品名后，点单价框会浮出该批发商对这个商品的历史报价，**按最新进货日期排序**，点一条即填入。用的是自绘浮层，不是 `datalist`，不会被输入法或下拉框遮住；也避开了浏览器原生下拉点不中、样式不可控的问题。
- **商品名联想**：输入 **2 个字以上**才对当前批发商的历史商品做模糊匹配（空格分词，多个词都要命中）。该批发商的商品**少于 15 种**时，点一下输入框就直接列出全部清单让你点选，不用打字。
- 明细行：商品名 / 单位 / 数量 / 单价 / 小计；「＋ 添加商品」增行，行尾 × 删行（只剩一行时改为清空内容，不会把表格删掉）。
- 底部实时显示 **总数量 N ｜ 合计金额 ￥X.XX**。
- 保存时：日期必填且必须真实存在；批发商名非空则自动入库为档案。

### 3. 批发商管理

**上方表单**：名称（必填）/ 联系人 / 电话 / 备注；列表里的「编辑」会把内容带上来改成修改。

**下方列表**

| 列 | 说明 |
| --- | --- |
| `#` | 序号；点表头可恢复默认顺序（按录入先后） |
| 批发商 / 联系人 / 电话 / 备注 | 档案信息，空值显示 `—` |
| 进货单数 | 该家名下单据数，**点表头排序**（先多到少，再点少到多） |
| 累计金额 | 累计进货额，**点表头排序**（按数值比，不受千分位影响） |
| 操作 | 编辑 / 删除，整列居中 |

列表上方一行汇总：`共 N 家 · 关联进货单 N 单 · 累计金额 ￥…`

**点任意一行 → 进详情（供货商品与最新报价）**

- 信息条三行排版：联系人 / 电话 一行、备注独占一行、进货单数 + 累计金额、商品种类 + 累计数量；标签列固定宽度右对齐，**中文冒号纵向对齐**；未填的字段显示浅灰 `—`。
- 商品表：`#`、商品名称、单位、进货次数、累计数量、**最新单价**（蓝色加粗）、最新报价日期、历史价格区间（最低～最高）。
- 表头上方搜索框**只按商品名称过滤**（单位不参与），命中高亮，右侧显示 `匹配 M / N 种商品`。
- 右上角「← 返回批发商列表」。

**窄屏（≤820px）**：批发商列表自动隐藏「联系人 / 电话 / 备注」三列，只留 `# / 批发商 / 进货单数 / 累计金额 / 操作`，并收紧列宽与内边距，手机上不用左右拖动也能一屏看完；PC 端列全保留。

## 四、几条关键规则（最容易被忽略的部分）

### 1. 日期必须真实存在

不只校验格式，还按日历校验（含闰年）：

| 输入 | 结果 |
| --- | --- |
| `2026-02-31` | 拒绝，提示「2026 年 2 月只有 28 天，没有 31 日」 |
| `2026-02-29` | 拒绝（2026 非闰年） |
| `2024-02-29` | 通过 |
| `2026-13-01` | 拒绝（13 月不存在） |
| `2026-04-31` | 拒绝（4 月只有 30 天） |
| `2026-11-00` / `2026-11-32` | 拒绝 |
| 年份 <1900 或 >2100 | 拒绝 |
| `2026/1/5`、`2026.1.5`、`2026-1-5` | 通过，自动归一化为 `2026-01-05` |

三个拦截点：

1. **录入 / 编辑**：失焦即校验，非法变红框 + 顶部提示（保留原输入方便改）；点保存再校验一次，非法不写库。
2. **筛选**：非法日期不进入筛选，提示后回退到上一次生效的日期，列表不动——避免「框里写着 6 月 31 日、列表却是全量」。
3. **服务端兜底**：`ajax=save` 自己再校验，绕过页面直接发请求也写不进去；`ajax=list&d=非法` 直接忽略。

### 2. 数量：最多两位小数，步长粘在行上

| 当前值 | 点一次加/减的步长 |
| --- | --- |
| `12`（整数） | `1` |
| `12.5`（一位小数） | `0.1` |
| `12.55`（两位小数） | `0.01` |
| `12.50`（末尾 0，按 12.5 算） | `0.1` |
| 清空 | 回到 `1` |

- 输入第三位小数会**即时截断**（不四舍五入，避免数字来回跳）。
- 步长「记住」是哪种小数位，不随显示变化：`1.2 → … → 2 → 2.1`，显示成整数 `2` 时也不会突然变成「一步加 1」。手输一个新的整数才回到默认步长 1。

### 3. 单价一律两位小数

手输、历史价填入、保存、列表显示，全部格式化到两位小数，避免出现 `12.3` 与 `12.30` 两种写法。

### 4. 「最新报价」不是「最后插入的那条」

按 `(进货日期 → 进货单 id → 明细 id)` 逐级比较取最靠后的一条。补录一张日期更早的旧单，不会把老价格顶成最新价。

### 5. 改名同步历史单，删档案不删账

- 批发商改名 → 所有历史进货单里的该名字同步更新，统计口径不断。
- 删除批发商 → 只删档案，名下进货单原样保留。

## 五、数据结构

数据库：`orders.sqlite`（与程序文件同目录，WAL 模式）

```sql
batches        -- 进货单，一单一条
  id          INTEGER PK
  wholesaler  TEXT    -- 批发商名（对应 wholesalers.name）
  odate       TEXT    -- 进货日期 YYYY-MM-DD
  note        TEXT
  created_at  TEXT

items          -- 单据里的商品明细
  id          INTEGER PK
  batch_id    INTEGER -- → batches.id（索引 idx_items_batch）
  name        TEXT
  unit        TEXT
  qty         REAL
  price       REAL

wholesalers    -- 批发商档案
  id          INTEGER PK
  name        TEXT    -- 唯一索引 idx_wholesalers_name
  contact     TEXT
  phone       TEXT
  note        TEXT
  created_at  TEXT
```

金额一律实时算 `SUM(qty * price)`，不存冗余汇总字段——改了明细统计自动跟上，不会出现「明细对、总额对不上」。

## 六、接口一览

所有交互走同一个入口，用 `?ajax=` 区分，返回 JSON（中文不转义）。

| 端点 | 方法 | 参数 | 作用 |
| --- | --- | --- | --- |
| `?ajax=list` | GET | `q` 关键词、`d` 日期、`w` 批发商、`page`、`per` | 列表 HTML + 分页 |
| `?ajax=stats` | GET | — | 四个统计数 |
| `?ajax=batch&id=` | GET | `id` | 单张单 + 明细（编辑用） |
| `?ajax=save` | POST | `id`（0=新增）、`odate`、`wholesaler`、`note`、`items[]` | 新增 / 更新（事务写入，日期服务端校验） |
| `?ajax=delete` | POST | `id` | 删除整单（含明细） |
| `?ajax=whlist` | GET | — | 批发商列表 + 各自单数 / 金额 + 汇总 |
| `?ajax=whdetail&id=` | GET | `id` | 该家供货商品、最新单价、历史区间 |
| `?ajax=wsave` | POST | `id`、`name`、`contact`、`phone`、`note` | 新增 / 修改批发商（改名同步历史单） |
| `?ajax=wdelete` | POST | `id` | 删除批发商档案（不动进货单） |
| `?ajax=prices&w=` | GET | `w` 批发商名 | 该家每个商品最近 8 个不同历史单价，按最新排序 |
| `?ajax=names&q=&w=&scope=` | GET | `q` 关键词（空格分词）、`w` 批发商、`scope=wh/all` | 商品名联想；`q` 为空时返回该家商品总数，少于 15 种连清单一起给 |

## 七、备份与维护

- **备份就是一个文件**：复制 `orders.sqlite`。开了 WAL，若同时有 `-wal` / `-shm`，停服务后三个一起拷最稳。
- **换机器**：程序文件 + `orders.sqlite`，拷走即用。
- **看数 / 导出 Excel**：用 DB Browser for SQLite 打开 `orders.sqlite`，把 `items` 导出 CSV 再拖进 Excel。
- **改主题色**：CSS 顶部 `:root` 里的 `--primary` / `--primary-strong` 决定蓝色主色，改一处全站生效。

## 八、常见问题

**Q：`php -l` 报 `Module "com_dotnet" is already loaded`？**
看到 `No syntax errors detected` 就行。那条是 PHP 配置重复加载扩展的告警，跟本系统无关。

**Q：`php -S` 下页面偶尔卡一下？**
内置服务器单进程，一次只处理一个请求。自用够用，多人请上 Apache / Nginx / php-fpm。

**Q：改了程序文件名，数据还在吗？**
在。数据库按目录定位，不认文件名，同目录换名字不影响数据。

**Q：删掉的批发商会不会又冒出来？**
不会。自动导入只在批发商表为空时执行一次；之后只在新增进货单时增量补充。

**Q：日期一定要手打成 `2026-01-05` 吗？**
不用。`2026/1/5`、`2026.1.5`、`2026-1-5` 失焦后都会补零成标准格式；点输入框还能直接弹日历选。

**Q：数量打三位小数为什么变成两位？**
刻意设计：防止误输入把金额算错，超出的第三位直接截断。

**Q：单价输入框怎么没有上下箭头了？**
有意去掉的。页面上经常在列表里滚动，箭头会跟着滚轮被动改数，把价格改花。现在只能手输或点历史价。

**Q：为什么某家「进货单数」和列表里的单据数对不上？**
两者口径一致，都按批发商名称统计。若手工改过数据库里的 `batches.wholesaler` 而没同步改名，口径就会断——正常在页面上改名不会有这个问题。
