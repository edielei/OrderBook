# 进货簿

一个人的小店记进货账：一个 PHP 文件 + 一个 SQLite 数据库。没有框架、没有 MySQL、不需要任何构建步骤，丢到任意支持 PHP 的目录里访问就能用。

## 这是什么

三个问题说清楚：

- **这是什么？** 记录「向批发商进货」的账本。一张进货单 = 一个批发商 + 一个日期 + 若干商品明细（名称 / 规格 / 单位 / 数量 / 单价）。
- **有什么用？** 代替纸本账。按关键词、批发商、日期翻历史单据；自动汇总每家进了多少单、花了多少钱；还能查某家供货过哪些商品、最近报价多少、历史价格区间在哪。
- **怎么用？** 打开页面 →「录入进货单」记账 →「进货记录」查账 →「批发商管理」维护联系人、看报价。首次访问自动建库，不用配置。

适合个人小店或内网单点使用。程序本身不含账号体系，不要直接暴露在公网。

## 快速开始

**环境**：PHP 8.0 及以上（`pdo_sqlite` 扩展，PHP 默认自带）、任意现代浏览器。不需要 MySQL、Node、构建工具。

**三种启动方式**

1. 本机最快：`php -S 127.0.0.1:8000 -t .`，然后访问 `http://127.0.0.1:8000/`
2. 已有站点（Apache / Nginx / 宝塔 / phpstudy）：把程序文件放进站点目录并命名为 `index.php`，访问站点根路径即可
3. 内网多人：挂到 Apache / Nginx / php-fpm 后面；`php -S` 是单进程，多人同时操作会排队

**首次访问会发生什么**

1. 在程序文件同目录创建 `orders.sqlite`（已存在则复用，不清空）
2. 自动建表 `batches` / `items` / `wholesalers` 及索引；老库缺 `items.spec` 列会自动补上
3. 若批发商档案为空，把历史进货单里出现过的批发商名导入一次（之后不再自动导入，删掉的不复活）

数据库跟着目录走、不认文件名，移动目录时把 `orders.sqlite` 一起挪。

## 进货记录

顶部四张统计卡：进货单数、累计金额、本月金额、本月单数，增删改后即时刷新。

搜索与筛选是两个区域，逻辑上是「同时满足」：

- 搜索区：关键词 + 搜索按钮，匹配商品名、规格、单位、批发商、备注
- 筛选区：批发商下拉、日期、清除筛选；已生效的条件显示成 chip，点 `×` 单独摘掉

日期框点一下即弹日历，也可以直接手输 `2026-1-5`。点单据头上的日期或批发商名，可一键把它们加进筛选。

列表按「进货日期倒序 → 同日录入顺序倒序」排列，补录旧单也会落到正确位置。每张单可展开看明细，右上角有打印 / 编辑 / 删除。明细表点表头即排序（商品名 / 单位 / 数量 / 单价 / 小计），当前列变蓝并带箭头，点 `#` 恢复单据内原始序号。

分页：`共 N 条 · 每页 10 / 20 / 50 / 100`。

打印为 A4 单页：另开一个隐藏 iframe 装自包含的打印稿，打印完自动移除；iOS 上没有 iframe 打印时退回页面内打印。

## 录入 / 编辑进货单

- **日期**：点输入框弹日历（键盘 Tab 进来也会弹），也支持手输 `2026-1-5` 自动补零
- **批发商**：可手输新名字，也可从已有档案的下拉候选里选
- **规格**：非必填，`500ml 瓶装`、`10包×3层` 这类写法都行；填完商品名后点规格框，会按「这家批发商 + 这个商品名」的历史记录给候选
- **单价**：手输，去掉上下箭头、不响应滚轮（避免滚动页面时误改价格），失焦规整成「最少两位、最多四位」小数；点单价框会浮出这家对这个商品的历史报价，按最新进货日期排序，点一条即填入
- **小计可手填**：小计列平时自动显示「数量 × 单价」，也可以直接填这一行的实付总价（如 12.5），失焦后按数量反算出单价（`12.5 ÷ 6 = 2.0833`），省去自己除；回头改数量或单价，小计回到自动计算
- **商品名联想**：输入 2 个字以上才对当前批发商的历史商品做模糊匹配（空格分词，多个词都要命中）；该家商品少于 15 种时，点一下输入框直接列出清单供点选
- 明细行可增可删，底部实时显示总数量与合计金额；保存时日期必填并校验，批发商名非空则自动入档

## 批发商管理

**上方表单**：名称（必填）/ 联系人 / 电话 / 备注；列表里的「编辑」会把内容带上来改成修改。

**列表**共 5 列：`#` / 批发商 / 联系人 / 联系电话 / 操作，按录入先后排列。卡片标题右侧跟一个小灰字计数：`共 N 家`，搜索过滤时变成 `匹配 N 家`。

- 没填的联系人或电话显示浅灰 `—`
- 存了多个号码会按 `, ， 、 ; ； /` 拆开，一个号码一行
- 搜索命中名称 / 联系人 / 电话时高亮

**点任意一行进详情（供货商品与最新报价）**

- 信息条竖排三行：联系人 / 电话 / 备注。标签在左列（小号灰字），值在右列，列宽由最长的标签撑开，三个值落在同一条竖线上；备注过长时在值列内折行，最多两行。底部一行统计：进货单数、商品种类、累计数量、累计金额
- 商品表 8 列：`#` / 商品名称（名称下方带规格小字）/ 单位 / 进货次数 / 累计数量 / 最新单价 / 最新报价日期 / 历史价格区间，全部可点表头排序，点 `#` 回到首次进货先后；排序可与搜索叠加
- 表头上方左边是商品种数（`共 N 种商品`，搜索时变成 `匹配 M / N 种商品`），右边是搜索框，只按商品名称过滤
- 右上角「← 返回批发商列表」

**列宽与窄屏**：除 `#` 和名称列外按内容自适应，名称列吃掉剩余宽度，表头不折行、不横向滚动；≤820px 收紧列宽与内边距，≤560px 允许名称与电话断行，390px 宽下操作列仍完整可见。

## 使用规则

**日期必须真实存在**，不只校验格式，还按日历校验（含闰年）：

| 输入 | 结果 |
| --- | --- |
| `2026-02-31` | 拒绝，提示该月没有这一天 |
| `2026-02-29` | 拒绝（2026 非闰年） |
| `2024-02-29` | 通过 |
| `2026-13-01` / `2026-11-32` | 拒绝 |
| `2026/1/5`、`2026.1.5`、`2026-1-5` | 通过，归一化为 `2026-01-05` |

三个拦截点：录入 / 编辑失焦即校验，非法标红并保留原输入，保存时再校验一次；筛选框里的非法日期不进入筛选、回退到上一次生效值；服务端 `save` 与 `list` 各自再校验，绕过页面直接发请求也写不进去。

**数量最多两位小数**，加减步长跟着当前小数位走：整数步长 1、一位小数 0.1、两位小数 0.01；输入第三位小数即时截断（不四舍五入）；清空后回到 1。

**单价最少两位、最多四位小数**，手输、历史价填入、保存、显示口径统一。整数价仍是 `45.60` 这种两位写法；除不尽的价（如 12.5 元 6 瓶 = `2.0833`）保留四位，小计按「数量 × 单价」四舍五入到分，`2.0833 × 6 = 12.50`，账对得上。

**规格可以为空**，空的就不显示、不占位；详情里取该商品最近一次进货填的那条，最新那条没填就沿用上一次填过的。

**最新报价**不是「最后插入的那条」，而是按 `进货日期 → 进货单 id → 明细 id` 逐级比较取最靠后的一条，所以补录旧单不会把老价格顶成最新价。

**改名与删除**：批发商改名，历史进货单里的名字同步更新；删除批发商只删档案，名下单据原样保留。

**打印只出一页**：抬头、元信息、合计、备注都设为不可拆分，表格行也不许跨页；打印期间再点打印会提示等待，取消不会把浏览器停在空白页。

## 数据结构

数据库 `orders.sqlite` 与程序文件同目录：

```sql
batches        -- 进货单，一单一条
  id          INTEGER PK
  wholesaler  TEXT    -- 批发商名（对应 wholesalers.name）
  odate       TEXT    -- 进货日期 YYYY-MM-DD
  note        TEXT
  created_at  TEXT

items          -- 单据里的商品明细
  id          INTEGER PK
  batch_id    INTEGER -- → batches.id
  name        TEXT
  spec        TEXT    -- 规格，可空
  unit        TEXT
  qty         REAL
  price       REAL

wholesalers    -- 批发商档案
  id          INTEGER PK
  name        TEXT    -- 唯一索引
  contact     TEXT
  phone       TEXT
  note        TEXT
  created_at  TEXT
```

金额一律实时算 `SUM(qty * price)`，不存冗余汇总字段。

## 接口

所有交互走同一入口，用 `?ajax=` 区分，返回 JSON（中文不转义）。

| 端点 | 方法 | 参数 | 作用 |
| --- | --- | --- | --- |
| `?ajax=list` | GET | `q` 关键词、`d` 日期、`w` 批发商、`page`、`per` | 列表 HTML + 分页 |
| `?ajax=stats` | GET | — | 四个统计数 |
| `?ajax=batch&id=` | GET | `id` | 单张单 + 明细（编辑用） |
| `?ajax=save` | POST | `id`（0 = 新增）、`odate`、`wholesaler`、`note`、`items[]` | 新增 / 更新（事务写入，日期服务端校验） |
| `?ajax=delete` | POST | `id` | 删除整单（含明细） |
| `?ajax=whlist` | GET | — | 批发商列表 + 各自单数 / 金额 |
| `?ajax=whdetail&id=` | GET | `id` | 该家供货商品、最新单价、历史区间 |
| `?ajax=wsave` | POST | `id`、`name`、`contact`、`phone`、`note` | 新增 / 修改批发商（改名同步历史单） |
| `?ajax=wdelete` | POST | `id` | 删除批发商档案（不动进货单） |
| `?ajax=prices&w=` | GET | `w` 批发商名 | 该家每个商品最近 8 个历史单价 |
| `?ajax=specs&w=&n=` | GET | `w`、`n` 商品名 | 该商品最近 12 条历史规格 |
| `?ajax=names&q=&w=&scope=` | GET | `q` 关键词、`w` 批发商、`scope=wh/all` | 商品名联想；`q` 空时返回该家商品总数，少于 15 种连清单一起给 |

## 备份与维护

- **备份就是一个文件**：复制 `orders.sqlite`；若有 `-wal` / `-shm`，停服务后三个一起拷最稳
- **换机器**：程序文件 + `orders.sqlite` 拷走即用
- **导出数据**：用 DB Browser for SQLite 打开 `orders.sqlite`，把 `items` 导出 CSV
- **改主题色**：CSS 顶部 `:root` 里的 `--primary` / `--primary-strong`
- **改打印版式**：只改 CSS 里 `#printArea` 那一批规则，页面内打印与打印窗口共用

## 常见问题

**`php -l` 报 `Module "com_dotnet" is already loaded`？**
看到 `No syntax errors detected` 就行，那条是 PHP 配置重复加载扩展的告警，与本系统无关。

**`php -S` 下页面偶尔卡一下？**
内置服务器单进程，一次只处理一个请求。自用够用，多人请上 php-fpm。

**改了程序文件名，数据还在吗？**
在。数据库按目录定位，不认文件名。

**删掉的批发商会不会又冒出来？**
不会。自动导入只在档案为空时执行一次，之后只在新增进货单时增量补充。

**日期一定要手打成 `2026-01-05` 吗？**
不用。`2026/1/5`、`2026.1.5`、`2026-1-5` 失焦后都会补零成标准格式，点输入框还能直接弹日历。

**为什么某家「进货单数」和列表里的单据数对不上？**
两者都按批发商名称统计，名字首尾空白（含全角空格、不换行空格）在保存入库、档案保存、程序启动清洗三处统一处理。若手工改过数据库里的 `batches.wholesaler` 而没同步改名，口径仍会断；在页面上改名不会有这个问题。
